# Zenodo collection: individual PDFs

The current collection is [10.5281/zenodo.23459196](https://doi.org/10.5281/zenodo.23459196).
It contains 24 individual PDFs, totalling 5,329,765 bytes: eight manuscripts of
Papers I–IV and sixteen manuscripts and formalization companions of V, VI and
Notes I–II, in English and Spanish.

The automatic GitHub release integration had archived the entire repository in
one 1,489,009,075-byte ZIP. This included historical audit packages, rather than
the intended individual manuscripts. On 18 October 2026, the repository archive
was replaced using Zenodo's published-file correction procedure, retaining the
same DOI. The record type and descriptive metadata were restored to a preprint
collection. Every replacement PDF was checked against the unchanged PDF edition
at [10.5281/zenodo.23458871](https://doi.org/10.5281/zenodo.23458871), including a
fresh public download and checksum comparison after publication. This is a
packaging correction; it does not revise the manuscripts or Lean sources.

The [correction receipt](FILE_CORRECTION_RECEIPT.json) records the file names,
sizes, MD5 and SHA-256 checksums and the latest-version check. The earlier
publication receipt in `publication/preprint1.0` describes the original PDF
deposit and remains historical evidence. Per-work citation metadata continues
to identify that unchanged original PDF edition; the repository-level citation
and publication index identify the current corrected collection.

## Publication procedure

The Zenodo GitHub release webhook for this repository is disabled. Future
GitHub releases must not automatically replace the document collection with
the entire repository archive. Update the collection deliberately through
Zenodo: retain the individual PDFs, check the exact proposed file names, sizes
and checksums, and confirm both the published record and the series concept
DOI after publication. Keep formalization packages and full evidence in the
linked GitHub release assets. No credentials belong in this repository.
