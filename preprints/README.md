05_formalization and superseded. Only v1.23 is offered as the current
Paper IV manuscript. Its v0.8 public draft is [superseded](PAPER_IV/superseded/README.md).
Other manuscript versions occur solely in audit backups, including the
published v1.22 baseline. Unrelated working drafts are excluded. The released
Papers I–III packages are unchanged.
