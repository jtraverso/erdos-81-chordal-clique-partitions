# Documentary reproduction — Paper II v1.3

The final delivered TeX files are the checked rendering sources, following the Paper IV layout. Compile each file from its own directory using `tectonic --keep-logs FILE.tex`; Tectonic resolves the required TeX passes and converts XDV to PDF. Alternatively use the supplied script with the executable in `TECTONIC`. This procedure compiles documents only; it does not run Lean/Lake.

Markdown is the semantic source. Figure files and the existing typesetting resource are reused without mathematical changes. Their pre-existing licenses remain applicable. Recorded PDF bytes are bound by SHA-256; different compiler/runtime versions may produce different PDF bytes.

The [editorial audit](../../02_validation/01_INTERNAL_AUDITS/run_v1.3_editorial_release/10_REPORT/FINAL_INTERNAL_AUDIT_REPORT.md) contains the exact source comparison and compiler/visual evidence. The unchanged formal-source reproduction instructions remain available in the [previous package](https://github.com/jtraverso/erdos-81-chordal-clique-partitions/tree/eb335845bfa23375d5040ea31fc4f4b366346287/preprints/PAPER_II/03_reproducibility).
