# Release integrity — Preprint 1.0

The SHA-256 manifest identifies every file in this work, except the manifest itself. Source archives also carry their own formal-source manifests. Validation records describe the scope of each check.

From the repository root, run `python publication/preprint1.0/verify_release.py` to verify the complete public series manifest. This checks bytes; Lean builds and independent computational checks have separate instructions in the formalization companion.
